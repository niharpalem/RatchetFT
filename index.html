1 — Idea

Finetuning as a feedback loop

  • — By hand: pick a dataset, guess LoRA settings, train, eyeball what's failing, find more data, retrain, decide when to stop. Hours of an engineer's attention per task.
  • — With RatchetFT: type the task. The agent does every one of those decisions — and you watch it train live.
  • — The key signal is per-label accuracy. Instead of training blindly, it finds the one class that's failing and fixes exactly that.
  • — The ratchet: keep the best checkpoint, roll back any regression. Accuracy only clicks forward.

2 — Design

Six design decisions

What makes the loop autonomous, generic, and safe to let run.

IDDecisionWhy it matters
D1claude CLI as the brain Both agents (research + decision) are subprocess calls to the local claude CLI — no API key, no SDK. Module: app/agent/claude_cli.py.
D2Generic, no whitelist The agent picks any HF classification dataset; the loader auto-detects text/label columns and class names from the dataset's own features. The code knows nothing about the domain. Module: app/train/datasets.py.
D3Grounded dataset search The research agent queries the real HF Hub (huggingface_hub) for datasets that provably exist, then picks from that list — with a memory-based fallback if the Hub is unreachable. Module: app/agent/hf_search.py.
D4Agent owns the finish line No fixed accuracy target. The decision agent reads the accuracy trajectory and stops on plateau / good-enough. max_iters is only a safety fuse. Module: app/agent/decide.py.
D5The ratchet Track the best checkpoint; on a regression, roll the LoRA adapter back to the best snapshot so the next round builds on the high-water mark. Accuracy only clicks forward. Module: app/core/loop.py.
D6Swappable Trainer backend The loop talks to one Trainer interface. LocalTrainer (real LFM2+LoRA on MPS) today; MockTrainer / ModalTrainer behind the same seam. Module: app/train/base.py.

5 — Run

Quick start

See README.md and DEMO.md for the full walkthrough. TL;DR:

# 1. Activate the env
source .venv/bin/activate

# 2. (optional) pre-cache demo datasets so nothing stalls live
python prefetch.py

# 3. Launch — the claude CLI must be on PATH
uvicorn app.main:app --reload --port 8000

Open http://localhost:8000, type a task (e.g. classify the emotion in a sentence), set max loops, and hit Run. Watch the activity feed, the live training bar, and the per-label trend chart climb. The agent stops itself; the best adapter is saved under data/<exp>/checkpoints/.
