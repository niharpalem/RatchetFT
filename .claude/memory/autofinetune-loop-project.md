**RatchetFT** ("Ratchet Finetuning — only clicks forward") — hackathon project at `/Users/sainiharredddypalem/Desktop/personal work/hck_1` (.venv = uv, Python 3.12). An agent takes one task sentence → finds an HF dataset → picks LoRA config → trains a real LFM2-350M checkpoint → reads per-label metrics → diagnoses weak classes → adds targeted data OR tunes params → loops.

Key non-obvious decisions:
- **Agent brain = the local `claude` CLI via subprocess** (`app/agent/claude_cli.py`), NOT the Anthropic API — no API key. Mirrors the SAGE-X app at `Desktop/self_enhancing_grader/sage_x/local_testing`. NOTE: invoking `claude` directly as a Bash command fails inside Claude Code (nested sandbox), but spawning it from a Python `subprocess` works fine.
- **Real training works**: `LocalTrainer` (`app/train/local.py`) loads LFM2-350M + PEFT LoRA and trains on Apple Silicon MPS (M4 Pro, 48GB). Instruction-style SFT (prompt masked, loss on label tokens) + verbalizer eval (argmax label by log-prob) → per-label accuracy. Default in `app/main.py::_trainer()`. `MockTrainer` (fake/instant) and `ModalTrainer` (cloud stub) are alternates behind the same `Trainer` protocol (`app/train/base.py`, signature takes `dataset: dict`).
- **GENERIC, no whitelist** (user insisted — like SAGE-X "code knows nothing about the domain"): `app/train/datasets.py` auto-detects text field(s), label field, and label names from ANY HF classification dataset's features. The research agent proposes any HF dataset id (+config/field hints); real labels are set from data after the first checkpoint.
- **Proxy gotcha**: HF dataset downloads are blocked inside the Claude Code sandbox (corp proxy 403) but work fine in the user's own terminal. Once cached, load offline with `HF_HUB_OFFLINE=1`. `LiquidAI/LFM2-350M` and `dair-ai/emotion` are already cached.
- **Real ML reality**: aggressive oversampling of weak classes on the 350M model can cause catastrophic forgetting. The **ratchet is now built** (`loop.py`): tracks best overall, accepts only forward progress, and on a regression rolls the adapter back to the best snapshot (`LocalTrainer.snapshot_adapter`/`restore_adapter` via peft state dict) so the next round builds on the high-water mark. LoRA adapters are saved to disk per checkpoint at `data/<exp>/checkpoints/ckpt-<i>/`; best recorded in meta.
- **Agent owns the finish line**: no fixed accuracy target — the decision agent stops on plateau (sees the accuracy trajectory with deltas); `max_iters` is only a safety fuse (set in the UI, default 6).
- **Agent also sets the training budget + LoRA targets** (un-hardcoded): research returns examples_per_class, eval_per_class, and target_modules (validated against LFM2's real layers: q/k/v/out_proj, w1/w2/w3). Base model stays fixed at LFM2-350M by choice.
- UI: FastAPI + HTMX + Tailwind, SSE streams loop events; per-label trend chart (inline SVG) + ratchet badges (new-best/rolled-back); training step/loss prints to the uvicorn terminal. Run: `uvicorn app.main:app --reload --port 8000`. Tracing currently `data/<exp>/decisions.jsonl` (Raindrop later); compute swap to Modal later via `_trainer()`.
